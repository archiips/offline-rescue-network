# Automatic floor feasibility implementation plan

Goal: a separate foreground research workspace for public iPhone and responder iPad, testing Apple-provided logical floor and anchored relative-altitude inference. User approved continuation; no UW deployment or physical accuracy claim. Existing rescue workflow, coordinates, reported floor, secure histories and relay queues remain unchanged. This checkpoint never attaches estimates to SOS automatically.

Design: C++ owns a bounded pure relative-floor estimator exposed through a C ABI; Swift wraps it and supplies native Core Location/CMAltimeter observations. Logical level 0 means ground, not building signage. Relative mode needs an explicit known starting logical level and measured uniform floor height; no campus-wide guessed height. A short stable window near a floor center produces an unvalidated candidate; transition/noise/stale/missing/invalid input returns Unknown. Apple floor is shown separately rather than silently fused with an anchor or translated into signage. Confidence is explicitly unvalidated, with no numeric probability.

Research consulted 2026-10-09: Apple CLLocation.floor is optional; CLFloor.level ground=0 and does not map building numbering. CMAltimeter relativeAltitude measures change from its first event; availability/authorization checks and NSMotionUsageDescription required. Sources: https://developer.apple.com/documentation/corelocation/cllocation/floor ; https://developer.apple.com/documentation/corelocation/clfloor/level ; https://developer.apple.com/documentation/coremotion/cmaltimeter ; https://developer.apple.com/documentation/coremotion/cmaltitudedata/relativealtitude ; Wi-Fi restrictions remain docs/UW_LOCALIZATION_ROADMAP.md. No Wi-Fi scan, current-SSID entitlement, known UW AP map or indoor venue floor coverage is assumed.

Alternatives: GPS altitude/floor division rejected (no ground/floor reference and uncertain vertical accuracy); Wi-Fi-only classifier deferred until lawful accessible labeled data exists; beacon/UWB/phone-graph fusion deferred pending physical inputs. Direct Apple floor + transparent relative baseline yields testable behavior now without invented infrastructure. Thresholds are conservative research defaults, not validated physical accuracy.
